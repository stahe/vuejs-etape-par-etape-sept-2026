    8. Dialoguer avec le serveur

    Les exemples de ce chapitre interrogent le serveur JSON [RdvMedecins] : il doit être lancé ([npm run start:dev] dans le dossier [rdvmedecins-nestjs-json]), sur le port 8080, en même temps que le serveur de [Vite] des exemples, sur le port 5173.

    8.1. Exemple 17 : une première requête HTTP

    8.1.1. Le proxy de Vite

    La page de l'exemple vient de http://localhost:5173 (le serveur de [Vite]) ; l'API est sur http://localhost:8080. Pour un navigateur, ce sont deux origines différentes (le port fait partie de l'origine). Or, par sécurité, un navigateur n'autorise pas une page à lire les réponses d'une autre origine, sauf accord explicite du serveur (le mécanisme dit CORS). Et [fetch] n'envoie pas les cookies (donc pas le jeton) à une autre origine, sauf si on le lui demande ([credentials: 'include']) ET que le serveur l'accepte, toujours par CORS.

    Plutôt que d'ouvrir le serveur aux autres origines, on fait passer les requêtes de l'API par le serveur de Vite. C'est le proxy déclaré dans [vite.config.ts] :

  =========================================================================
  17-fetch/src/App.vue - une première requête HTTP vers le serveur
  -------------------------------------------------------------------------
  Le serveur JSON RdvMedecins doit être lancé (port 8080). On lui demande
  un captcha : GET /api/captcha -> { "id": "...", "svg": "<svg ...>" }.

    - fetch(url) : la fonction du navigateur qui envoie une requête HTTP.
      Elle renvoie une PROMESSE : on attend la réponse avec await ;
    - reponse.ok : vrai pour un code 2xx ; reponse.json() lit le corps
      JSON (encore une promesse) ;
    - l'adresse est RELATIVE (/api/captcha) : la requête part vers le
      serveur de la page, Vite (port 5173), qui la transmet au serveur JSON
      (port 8080) grâce à son proxy (cf. vite.config.ts) ;
    - trois états à afficher : en cours, réussi, en erreur.
  =========================================================================
-->
<script setup lang="ts">
import { onMounted, ref } from 'vue';

// ce que renvoie GET /api/captcha
interface Captcha {
  id: string;
  svg: string;
}

const captcha = ref<Captcha | null>(null);
const enCours = ref(false);
const erreur = ref<string | null>(null);
const nbRequetes = ref(0);

async function charger(): Promise<void> {
  enCours.value = true;
  erreur.value = null;
  try {
    const reponse = await fetch('/api/captcha');
    nbRequetes.value++;
    if (!reponse.ok) {
      // le serveur a répondu, mais par une erreur (4xx, 5xx) - ou c'est
      // Vite qui répond 502/504 parce que le serveur JSON est arrêté
      throw new Error(`le serveur a répondu ${reponse.status} ${reponse.statusText}`);
    }
    captcha.value = (await reponse.json()) as Captcha;
  } catch (e) {
    // fetch lui-même échoue quand aucune réponse n'arrive (réseau coupé...)
    erreur.value = e instanceof Error ? e.message : String(e);
    captcha.value = null;
  } finally {
    enCours.value = false;
  }
}

// au premier affichage, on charge un captcha
onMounted(charger);
</script>

  =========================================================================
  18-connexion/src/App.vue - se connecter au serveur RdvMedecins
  -------------------------------------------------------------------------
    1. au démarrage : GET /api/auth/moi - sommes-nous déjà connectés ?
       (après un F5, le client a tout oublié ; le serveur, lui, lit le cookie) ;
    2. connexion : POST /api/auth/login, corps JSON { login, password,
       captchaId, captcha }. En cas de succès, le serveur dépose le cookie
       httpOnly du jeton JWT : notre code ne le voit JAMAIS (essayez
       document.cookie dans la console : il n'y est pas) ;
    3. requête protégée : GET /api/medecins. Le navigateur y joint le cookie
       tout seul (même origine) ;
    4. déconnexion : POST /api/auth/logout - le serveur efface le cookie.

  Un cookie appartient à une machine (localhost) et à un chemin (/api) : il
  est donc commun à TOUS les exemples. Une fois connecté ici, les exemples 19 et 20
  le sont aussi.
  =========================================================================

<script setup lang="ts">
import { onMounted, reactive, ref } from 'vue';

interface Utilisateur {
  login: string;
  nom: string;
  role: 'ADMIN' | 'DOCTOR' | 'USER';
}
interface Medecin {
  id: number;
  titre: string;
  prenom: string;
  nom: string;
}
// la forme de TOUTES les erreurs de l'API
interface ErreurApi {
  statusCode: number;
  cle: string;
  params?: Record<string, string>;
}

// les quelques messages dont cet exemple a besoin (l'exemple 20 utilisera vue-i18n)
const MESSAGES: Record<string, string> = {
  'LOGIN.ERROR': 'Login ou mot de passe incorrect.',
  'ERRORS.WRONG_CAPTCHA': "Les caractères recopiés ne correspondent pas à l'image.",
  'ERRORS.TOO_MANY_ATTEMPTS': 'Trop de tentatives infructueuses. Réessayez plus tard.',
};

const utilisateur = ref<Utilisateur | null>(null);
const medecins = ref<Medecin[]>([]);
const captcha = ref<{ id: string; svg: string } | null>(null);
const saisie = reactive({ login: 'admin', password: '', captcha: '' });
const erreur = ref<string | null>(null);
const pret = ref(false); // la vérification de départ est-elle terminée ?

async function chargerCaptcha(): Promise<void> {
  captcha.value = await (await fetch('/api/captcha')).json();
  saisie.captcha = '';
}

// 1. qui est connecté ? 200 -> l'utilisateur ; 401 -> personne
async function verifierSession(): Promise<void> {
  const reponse = await fetch('/api/auth/moi');
  if (reponse.ok) {
    utilisateur.value = await reponse.json();
    await chargerMedecins();
  } else {
    await chargerCaptcha();
  }
  pret.value = true;
}

// 2. la connexion
async function seConnecter(): Promise<void> {
  erreur.value = null;
  const reponse = await fetch('/api/auth/login', {
    method: 'POST',
    // le serveur refuse (415) un POST qui n'est pas en JSON
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      login: saisie.login,
      password: saisie.password,
      captchaId: captcha.value?.id,
      captcha: saisie.captcha,
    }),
  });
  if (reponse.ok) {
    utilisateur.value = await reponse.json();
    saisie.password = '';
    await chargerMedecins();
    return;
  }
  // une erreur : le corps JSON dit laquelle ; chaque image ne sert qu'une fois
  const e = (await reponse.json()) as ErreurApi;
  erreur.value = `${reponse.status} - ${MESSAGES[e.cle] ?? e.cle}`;
  await chargerCaptcha();
}

// 3. une requête protégée
async function chargerMedecins(): Promise<void> {
  const reponse = await fetch('/api/medecins');
  medecins.value = reponse.ok ? await reponse.json() : [];
}

// 4. la déconnexion
async function seDeconnecter(): Promise<void> {
  await fetch('/api/auth/logout', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: '{}' });
  utilisateur.value = null;
  medecins.value = [];
  await chargerCaptcha();
}

onMounted(() => {
  verifierSession().catch(() => {
    erreur.value = 'Le serveur JSON RdvMedecins est-il lancé (port 8080) ?';
    pret.value = true;
  });
});
</script>

<template>
  <div class="container py-4" style="max-width: 640px">
    <h1 class="h3 mb-3">Exemple 18 - connexion au serveur</h1>
    <p v-if="!pret" class="text-muted">Vérification de la session...</p>

    <!-- connecté -->
    <div v-else-if="utilisateur" class="card p-3">
      <p>Connecté : <strong>{{ utilisateur.nom }}</strong> ({{ utilisateur.login }}),
        rôle <span class="badge text-bg-primary">{{ utilisateur.role }}</span></p>
      <h2 class="h6">GET /api/medecins</h2>
      <ul>
        <li v-for="m in medecins" :key="m.id">{{ m.titre }} {{ m.prenom }} {{ m.nom }}</li>
      </ul>
      <p class="small text-muted">Rechargez la page (F5) : vous restez connecté.</p>
      <button class="btn btn-outline-secondary align-self-start" @click="seDeconnecter">Se déconnecter</button>
    </div>

    <!-- pas connecté : le formulaire -->
    <form v-else class="card p-3" @submit.prevent="seConnecter">
      <div class="mb-2">
        <label class="form-label" for="login">Login</label>
        <input id="login" v-model="saisie.login" class="form-control" autocomplete="username">
      </div>
      <div class="mb-2">
        <label class="form-label" for="password">Mot de passe</label>
        <input id="password" v-model="saisie.password" type="password" class="form-control" autocomplete="current-password">
      </div>
      <div class="mb-3">
        <label class="form-label" for="captcha">Recopiez les caractères de l'image</label>
        <div class="d-flex align-items-center gap-3 mb-2">
          <div v-if="captcha" v-html="captcha.svg"></div>
          <a href="#" class="small" @click.prevent="chargerCaptcha">Autre image</a>
        </div>
        <input id="captcha" v-model="saisie.captcha" class="form-control" autocomplete="off">
      </div>
      <button class="btn btn-primary">Se connecter</button>
      <p class="small text-muted mt-2 mb-0">Comptes : admin, pelissier, martin... (mot de passe = login).</p>
    </form>

    <div v-if="erreur" class="alert alert-danger mt-3">{{ erreur }}</div>
  </div>
</template>

    // =========================================================================
// commun/api.ts - UNE fonction pour toutes les requêtes vers l'API
// -------------------------------------------------------------------------
// Dans l'exemple 18, chaque appel à fetch répétait les mêmes gestes :
// préfixe /api, entête Content-Type, JSON.stringify, test de reponse.ok,
// lecture du corps d'erreur... On les regroupe ici, une fois pour toutes :
//
//   const medecins = await api.get<Medecin[]>('/medecins');
//   await api.post('/rendez-vous', { jour, idCreneau, idClient });
//
//   - en cas de succès, la promesse renvoie le corps JSON, TYPÉ ;
//   - en cas d'échec, elle est REJETÉE avec une ErreurApi, qui porte la
//     clé de traduction envoyée par le serveur (et, s'il y en a, ses
//     paramètres et l'erreur de chaque champ).
// Utilisé par les exemples 19 et 20 ; l'étude de cas en reprend le principe.
// =========================================================================

export class ErreurApi extends Error {
  constructor(
    public readonly statusCode: number, // 0 : le serveur n'a pas répondu
    public readonly cle: string, // ex : 'ERRORS.LOGIN_TAKEN'
    public readonly params: Record<string, string> = {},
    public readonly champs: Record<string, string> = {},
  ) {
    super(cle);
    this.name = 'ErreurApi';
  }
}

type Methode = 'GET' | 'POST' | 'PUT' | 'DELETE';

export async function requete<T>(methode: Methode, url: string, corps?: unknown): Promise<T> {
  let reponse: Response;
  try {
    reponse = await fetch(`/api${url}`, {
      method: methode,
      // un corps -> du JSON (le serveur refuse un POST qui n'en est pas)
      headers: corps !== undefined ? { 'Content-Type': 'application/json' } : {},
      body: corps !== undefined ? JSON.stringify(corps) : undefined,
    });
  } catch {
    // aucune réponse (réseau coupé...)
    throw new ErreurApi(0, 'ERRORS.SERVER_UNREACHABLE');
  }

  // le corps est lu comme du texte, puis converti : une réponse vide, ou
  // qui n'est pas du JSON (serveur JSON arrêté : c'est Vite qui répond),
  // ne doit pas faire planter l'application
  const texte = await reponse.text();
  let donnees: unknown = null;
  try {
    donnees = texte ? JSON.parse(texte) : null;
  } catch {
    donnees = null;
  }

  if (!reponse.ok) {
    const e = (donnees ?? {}) as { cle?: string; params?: Record<string, string>; champs?: Record<string, string> };
    throw new ErreurApi(reponse.status, e.cle ?? 'ERRORS.SERVER_UNREACHABLE', e.params, e.champs);
  }
  return donnees as T;
}

// des raccourcis, plus lisibles à l'usage
export const api = {
  get: <T>(url: string) => requete<T>('GET', url),
  post: <T>(url: string, corps: unknown = {}) => requete<T>('POST', url, corps),
  put: <T>(url: string, corps: unknown) => requete<T>('PUT', url, corps),
  delete: <T>(url: string, corps?: unknown) => requete<T>('DELETE', url, corps),
};

    • ligne 32 : une fonction générique : [T] est le type du corps attendu en cas de succès. [requete<Personne[]>('GET', '/medecins')] renvoie une [Promise<Personne[]>] ;

<script setup lang="ts">
import { onMounted, reactive, ref } from 'vue';
import { api, ErreurApi } from './api';
import type { Captcha, Utilisateur } from './types';

const emit = defineEmits<{ change: [utilisateur: Utilisateur | null] }>();

const utilisateur = ref<Utilisateur | null>(null);
const captcha = ref<Captcha | null>(null);
const saisie = reactive({ login: 'admin', password: '', captcha: '' });
const erreur = ref<string | null>(null);

async function nouveauCaptcha(): Promise<void> {
  captcha.value = await api.get<Captcha>('/captcha');
  saisie.captcha = '';
}

function changer(u: Utilisateur | null): void {
  utilisateur.value = u;
  emit('change', u);
}

onMounted(async () => {
  try {
    changer(await api.get<Utilisateur>('/auth/moi'));
  } catch {
    changer(null); // 401 : personne n'est connecté
    await nouveauCaptcha().catch(() => (erreur.value = 'Le serveur JSON est-il lancé (port 8080) ?'));
  }
});

async function seConnecter(): Promise<void> {
  erreur.value = null;
  try {
    const u = await api.post<Utilisateur>('/auth/login', {
      login: saisie.login,
      password: saisie.password,
      captchaId: captcha.value?.id,
      captcha: saisie.captcha,
    });
    saisie.password = '';
    changer(u);
  } catch (e) {
    erreur.value = e instanceof ErreurApi ? `${e.statusCode} ${e.cle}` : String(e);
    await nouveauCaptcha();
  }
}

async function seDeconnecter(): Promise<void> {
  await api.post('/auth/logout');
  changer(null);
  await nouveauCaptcha();
}

import { computed, ref, watch } from 'vue';
import BarreConnexion from '../../commun/BarreConnexion.vue';
import { ErreurApi } from '../../commun/api';

const medecins = ref<Personne[]>([]);
const clients = ref<Personne[]>([]);
const idMedecin = ref<number | null>(null);

const agenda = ref<Agenda | null>(null);

const message = ref<{ type: 'success' | 'danger'; texte: string } | null>(null);

function demain(): string {
  const d = new Date(Date.now() + 24 * 3600 * 1000);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}

function horaire(c: CreneauAgenda): string {
  const hm = (h: number, m: number) => `${h}:${String(m).padStart(2, '0')}`;
  return `${hm(c.hdebut, c.mdebut)} - ${hm(c.hfin, c.mfin)}`;
}

// une erreur de l'API devient un message (sa clé, faute de dictionnaire ici)
function signaler(e: unknown): void {
  message.value = { type: 'danger', texte: e instanceof ErreurApi ? `${e.statusCode} ${e.cle}` : String(e) };
}

// connexion / déconnexion : on (re)charge ce que ce rôle a le droit de voir
async function surConnexion(u: Utilisateur | null): Promise<void> {
  utilisateur.value = u;
  agenda.value = null;
  medecins.value = [];
  clients.value = [];
  if (u === null) {
    return;
  }
  try {
    medecins.value = await rdvmedecins.getMedecins();
    // la liste des patients : seulement pour ADMIN et DOCTOR (un USER recevrait 403)
    clients.value = gestionnaire.value ? await rdvmedecins.getClients() : [];
  } catch (e) {
    signaler(e);
  }
}

async function chargerAgenda(): Promise<void> {
  if (idMedecin.value === null) {
    return;
  }
  try {
    agenda.value = await rdvmedecins.getAgenda(idMedecin.value, jour.value);
  } catch (e) {
    agenda.value = null;
    signaler(e);
  }
}

// l'agenda suit le choix du médecin et du jour
watch([idMedecin, jour], () => {
  message.value = null;
  chargerAgenda();
});

async function reserver(c: CreneauAgenda): Promise<void> {
  try {
    await rdvmedecins.reserver(jour.value, c.id, gestionnaire.value ? (idClient.value ?? undefined) : undefined);
    message.value = { type: 'success', texte: `Créneau ${horaire(c)} réservé.` };
  } catch (e) {
    signaler(e);
  }
  await chargerAgenda();
}

async function annuler(c: CreneauAgenda): Promise<void> {
  try {
    await rdvmedecins.annuler(c.idRv as number);
    message.value = { type: 'success', texte: `Rendez-vous de ${horaire(c)} annulé.` };
  } catch (e) {
    signaler(e);
  }
  await chargerAgenda();
}
</script>

const clients = ref<Personne[]>([]);
const estAdmin = computed(() => utilisateur.value?.role === 'ADMIN');

// le formulaire : idEdite === null -> création, sinon modification
const idEdite = ref<number | null>(null);
const saisie = reactive({ titre: 'Mr', prenom: '', nom: '', login: '', password: '', version: 0 });
// les erreurs renvoyées par le serveur
const erreurChamps = ref<Record<string, string>>({});
const erreurPage = ref<ErreurApi | null>(null);
const succes = ref<string | null>(null);

async function surConnexion(u: Utilisateur | null): Promise<void> {
  utilisateur.value = u;
  clients.value = [];
  if (u?.role === 'ADMIN') {
    await recharger();
  }
}

async function recharger(): Promise<void> {
  clients.value = await api.get<Personne[]>('/clients');
}

function nouveau(): void {
  idEdite.value = null;
  Object.assign(saisie, { titre: 'Mr', prenom: '', nom: '', login: '', password: '', version: 0 });
  effacerErreurs();
}

function editer(c: Personne): void {
  idEdite.value = c.id;
  // la VERSION lue avec la fiche repart avec la modification : si quelqu'un
  // a modifié la fiche entre-temps, le serveur répondra 409 CONCURRENT_UPDATE
  Object.assign(saisie, { titre: c.titre, prenom: c.prenom, nom: c.nom, login: c.login ?? '', password: '', version: c.version });
  effacerErreurs();
}

function effacerErreurs(): void {
  erreurChamps.value = {};
  erreurPage.value = null;
  succes.value = null;
}

// le texte d'une erreur, dans la langue courante, avec ses paramètres
function texte(e: ErreurApi): string {
  return t(e.cle, e.params);
}

async function enregistrer(): Promise<void> {
  effacerErreurs();
  const corps = { ...saisie };
  try {
    const client =
      idEdite.value === null
        ? await api.post<Personne>('/clients', corps)
        : await api.put<Personne>(`/clients/${idEdite.value}`, corps);
    const message = t(idEdite.value === null ? 'FORM.AJOUTE' : 'FORM.MODIFIE', {
      nom: `${client.prenom} ${client.nom}`,
      login: client.login ?? '',
    });
    nouveau(); // formulaire vidé, messages effacés...
    succes.value = message; // ... sauf celui-ci
    await recharger();
  } catch (e) {
    if (!(e instanceof ErreurApi)) {
      throw e;
    }
    // l'erreur de chaque champ, et le message général
    erreurChamps.value = e.champs;
    erreurPage.value = e;
  }
}

async function supprimer(c: Personne): Promise<void> {
  const nom = `${c.prenom} ${c.nom}`;
  if (!(await confirmer(t('FORM.CONFIRMER_SUPPRESSION', { nom })))) {
    return;
  }
  effacerErreurs();
  try {
    await api.delete(`/clients/${c.id}`);
    succes.value = t('FORM.SUPPRIME', { nom });
  } catch (e) {
    erreurPage.value = e instanceof ErreurApi ? e : null;
  }
  await recharger();
}
